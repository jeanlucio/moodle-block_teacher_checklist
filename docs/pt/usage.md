# 📖 Como Usar

1. Adicione o bloco **Teacher Checklist** à página do seu curso.
2. O bloco lista imediatamente os primeiros problemas pendentes detectados automaticamente, com um contador para os demais.
3. Clique em **Ver checklist completo** para abrir o painel com suas três abas: **Pendentes**, **Ignorados** e **Minhas Tarefas Feitas**.
4. Adicione tarefas manuais pelo campo de texto no topo do painel.
5. Use os botões de cada item para marcá-lo como Feito, Ignorá-lo ou Restaurá-lo para Pendente.
6. Selecione vários itens com as caixas de seleção e use **Com selecionados** para atualizá-los de uma vez.
7. Desative a **Verificação Automática** se quiser usar o bloco apenas como lista manual.

### Quem pode usar

O bloco e o painel aparecem apenas para quem tem `moodle/course:update` no curso — por padrão, professores e gerentes. Estudantes nunca veem o bloco, mesmo num curso onde ele está instalado.
