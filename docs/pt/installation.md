# 🛠️ Instalação

1. Baixe o arquivo `.zip` ou clone este repositório.
2. Extraia a pasta para o diretório `blocks/` do seu Moodle e nomeie-a `teacher_checklist`.
   Caminho final: `seu-moodle/blocks/teacher_checklist/`
3. Acesse **Administração do site > Notificações** para executar a atualização do banco de dados.
4. Adicione o bloco **Teacher Checklist** a qualquer página de curso via **Ativar edição > Adicionar um bloco**.

```bash
git clone git@github.com:jeanlucio/moodle-block_teacher_checklist.git blocks/teacher_checklist
```
