# ✨ Funcionalidades

* 🔍 **Verificação automática:** detecta problemas comuns na configuração do curso sem nenhum trabalho manual (veja [Verificações automáticas](#checks)).
* 📋 **Itens manuais:** professores podem adicionar tarefas que o sistema não consegue detectar automaticamente.
* 👁️ **Rastreamento de status:** cada item pode ser marcado como **Feito**, **Ignorado** ou restaurado para **Pendente**.
* ⚡ **Ações em lote:** marque ou ignore vários itens de uma vez com um único clique.
* 🔄 **Alternar verificação:** a verificação automática pode ser desligada por curso, transformando o bloco numa lista puramente manual.
* 🎯 **Fila de correção precisa:** os envios pendentes seguem a regra do core do Moodle — só conta a última tentativa de um participante ativo, tarefas em grupo são tratadas e as prévias do próprio professor nos questionários são ignoradas.
* 💾 **Backup seguro:** itens manuais e a chave da verificação automática acompanham o backup do curso; os problemas automáticos são recalculados no curso de destino.
* 🔐 **Restrito a professores:** só quem pode atualizar o curso vê o bloco e o painel.
* 🔒 **Privacy API completa:** exportação e exclusão de dados suportadas.
* 🧩 **API pública:** outros plugins podem criar itens manuais num curso (veja [Para desenvolvedores](#developers)).
