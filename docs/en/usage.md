# 📖 Usage

1. Add the **Teacher Checklist** block to your course page.
2. The block immediately lists the first pending issues detected automatically, with a counter for the rest.
3. Click **View full report** to open the dashboard with its three tabs: **Pending**, **Ignored** and **My Completed Tasks**.
4. Add manual tasks with the text field at the top of the dashboard.
5. Use the buttons on each item to mark it as Done, Ignore it, or Restore it to Pending.
6. Select several items with the checkboxes and use **With selected** to update them at once.
7. Switch **Automatic Scan** off if you want to use the block only as a manual checklist.

### Who can use it

The block and the dashboard are shown only to users who hold `moodle/course:update` in the course — by default, teachers and managers. Students never see the block, even in a course where it is installed.
