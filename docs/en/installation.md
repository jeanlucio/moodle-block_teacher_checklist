# 🛠️ Installation

1. Download the `.zip` file or clone this repository.
2. Extract the folder into your Moodle `blocks/` directory and name it `teacher_checklist`.
   Final path: `your-moodle/blocks/teacher_checklist/`
3. Visit **Site administration > Notifications** to run the database upgrade.
4. Add the **Teacher Checklist** block to any course page via **Turn editing on > Add a block**.

```bash
git clone git@github.com:jeanlucio/moodle-block_teacher_checklist.git blocks/teacher_checklist
```
