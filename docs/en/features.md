# ✨ Features

* 🔍 **Automatic scanning:** detects common course configuration problems without any manual work (see [Automatic checks](#checks)).
* 📋 **Manual items:** teachers can add custom tasks that the system cannot detect automatically.
* 👁️ **Status tracking:** every item can be marked as **Done**, **Ignored**, or restored to **Pending**.
* ⚡ **Bulk actions:** mark or ignore several items at once with a single click.
* 🔄 **Toggle scan:** automatic scanning can be switched off per course, turning the block into a pure manual checklist.
* 🎯 **Accurate grading backlog:** pending submissions follow the Moodle core rule — only the latest attempt of an active participant counts, team assignments are handled, and a teacher's own quiz previews are ignored.
* 💾 **Backup safe:** manual items and the automatic-scan switch travel with the course backup; automatic issues are recalculated on the destination course.
* 🔐 **Private to teachers:** only users who can update the course see the block and the dashboard.
* 🔒 **Privacy-complete:** full Privacy API implementation, with data export and deletion.
* 🧩 **Public API:** other plugins can seed manual items into a course (see [For developers](#developers)).
